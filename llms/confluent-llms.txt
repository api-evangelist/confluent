# Confluent Documentation

Confluent is a data streaming platform built on Apache Kafka that enables real-time data integration, stream processing, and event-driven architecture at enterprise scale. Access documentation for Confluent Cloud (fully-managed), Confluent Platform (on-premises), and the open-source Apache Kafka ecosystem.

## Markdown renditions

Every link below that ends in `.md` returns clean Markdown (`Content-Type: text/markdown`), free of the navigation chrome that dominates the HTML. Most pages on docs.confluent.io follow this convention: replace the `.html` extension with `.md` to get the Markdown rendition of any page.

Auto-generated API reference (Javadoc, librdkafka, .NET, JavaScript, Python) has no Markdown rendition, so the few `.html` links below are deliberate.
